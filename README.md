# MangaMood
сайт для подбора тайтла манги/манхвы / Маньхуа по настроению (далее его основной функционал )
тест на 20 вопросов с 8 вариантами ответа где в каждом вопросе можно выбрать до 3 вариантов ответа и расставить по местам (1 самый близкий вариант 2 возможно подойдет 3 тоже подходит) к каждому варианту ответа привязаны 2 жанра и 3 тега и так строятся рекомендации после прохождения теста. 
база тайтлов будет подтягиваться через api ключ у Anilist 
так же будет личный профиль каждого пользователя (есть простая регистрация с паролем и логином без подвязки к почте ) так же система ачивок за каждое настроение (так называются жанры на сайте ) и награды ( аватарка за 15 тайтлов одного настроения и за 30 личный фон профиля ) 
в профиле так же отображаются ваш список прочтения и оценка работы ( 3 персонажи сюжет атмосфера критерия каждый по 5 звезд) и комментарии к работе 
так же в личном кабинете есть календарь настроений можно проходить тест по несколько раз за день и тогда на дне будут отображаться несколько значков 
у вас только будет видна библиотека где находятся работы в статусе в планах и прочитано 
переходя на тайтл можно видеть его среднюю оценку от пользователей а так же комментарии. на профиль человека можно перейти только кликнув на его комментарий. на профиле видно тайтлы в статусе прочитано автаркическ фон профиля и оценки с комментариями как лента к работам  
это основное буду еще дорабатывать
